# 맥북 문자 발송 테스트 키트 (팀원용)

우리 앱의 안내 문자는 **맥북의 메시지 앱이 아이폰을 통해 일반 문자(SMS)를 보내는 방식**으로 나갑니다.
이 키트는 **진행자 화면이나 마스터키 없이**, 내 맥북과 아이폰에서 그 방식이 되는지 **문자 1건**만 보내 확인하는 도구입니다.
(번호는 실행할 때 팝업으로 입력하고, 아무것도 저장하거나 올리지 않습니다.)

## 이렇게 진행하면 됩니다 (팀원 → 진행자에게 보내는 경우)
- **보내는 사람(팀원)**: 자기 맥북과 아이폰으로 아래 1~3단계를 하고, 3단계에서 **진행자의 휴대폰 번호**를 입력합니다.
- **받는 사람(진행자)**: 문자가 왔는지 확인하고 4단계 항목을 팀원에게 알려 줍니다. 보낸이 번호는 **팀원의 번호**로 보입니다(모르는 번호가 아니라 테스트 문자입니다).
- 서로 떨어져 있어도 됩니다. 단, 팀원이 아이폰·맥북 설정(1~2단계)을 할 때는 둘 다 팀원 손에 있어야 합니다.

## 준비물
- 맥북 1대 + 아이폰 1대 (**같은 Apple ID**로 로그인)
- 문자를 받아 볼 **다른 휴대폰** 1대 (진행자 번호, 친구 번호 등). 보내는 아이폰 자기 번호로는 확인이 어렵습니다.
- 파일 `sms-test.applescript`

## 1단계: 아이폰 설정 (한 번만)
아이폰 언어가 영어여도 같은 순서입니다.
1. **Settings(설정) → Messages(메시지)** 로 들어갑니다. (최신 iOS는 **Settings → Apps → Messages** 일 수 있어요. 안 보이면 설정 위쪽 검색창에 `Text Message Forwarding` 을 입력하세요.)
2. **iMessage** 가 켜져 있는지 확인합니다.
3. **Text Message Forwarding(문자 메시지 전달)** 을 열고, 목록에 있는 **내 맥북 이름의 토글을 켭니다.**
4. 맥북 화면에 **인증 번호(숫자)** 가 뜨면 아이폰에서 그 번호를 입력합니다.
   - 맥북이 목록에 없으면: 아이폰과 맥북이 같은 Apple ID인지, 맥북의 **Messages 앱 → Settings → iMessage** 에 로그인돼 있는지 확인하세요.

## 2단계: 맥북에서 메시지 앱 확인
1. 맥북의 **Messages(메시지)** 앱을 열어 로그인된 상태인지 확인합니다.
2. 새 메시지를 만들어 **다른 사람 번호로 직접 한 건** 보내 봅니다. 말풍선이 **초록색(SMS)** 으로 나가고 상대 폰에 도착하면 준비가 끝난 것입니다. (이것도 안 되면 위 1단계 설정 문제입니다.)

## 3단계: 테스트 스크립트 실행
1. `sms-test.applescript` 를 더블클릭하거나, **Script Editor(스크립트 편집기)** 로 엽니다. (응용 프로그램 → 유틸리티, 또는 Spotlight 에서 `Script Editor` 검색)
2. 위쪽 **▶(Run, 실행)** 버튼을 누릅니다.
3. 처음에는 **"Script Editor가 Messages를 제어하려고 합니다"** 같은 권한 창이 뜹니다. **OK(허용)** 를 누르세요.
   - 실수로 거부했다면: **System Settings(시스템 설정) → Privacy & Security(개인정보 보호 및 보안) → Automation(자동화)** 에서 Script Editor 의 Messages 를 켭니다.
4. 팝업에 **문자를 받을 번호(숫자만, 예: 01012345678)** 를 입력하고 OK 를 누릅니다.
5. "발송을 요청했어요" 창이 뜨면, **받는 휴대폰에 문자가 왔는지** 확인합니다.

## 4단계: 결과를 이렇게 알려주세요 (받는 사람이 확인해서 팀원에게 전달)
1. 받는 폰에 문자가 **도착했나요?** (몇 초~1분)
2. 문자 안의 **이모지(🧶 😊 💘)** 가 그대로 보이나요?
3. 도착한 문자는 일반 문자(SMS)였나요, 아니면 파란색 iMessage 였나요? (받는 사람이 아이폰이면 파랗게 올 수 있어요)
4. 오류가 났다면 창에 나온 **오류 문구를 그대로 복사**해서 알려주세요. (스크립트 편집기 아래쪽에 빨간 글씨로 나오는 문구도 같이요)
5. 맥북 OS 버전 (왼쪽 위 사과 메뉴 → About This Mac)

## 안 될 때 (자주 있는 원인)
| 증상 | 확인할 것 |
|---|---|
| 권한 창이 안 뜸/오류 | 시스템 설정 → 개인정보 보호 및 보안 → 자동화 에서 Script Editor 의 Messages 허용 |
| "발송을 요청했어요"인데 문자가 안 옴 | 2단계처럼 메시지 앱에서 직접 SMS 가 나가는지, 아이폰이 켜져 있고 인터넷에 연결돼 있는지 |
| 맥북이 문자 메시지 전달 목록에 없음 | 같은 Apple ID 로그인, iMessage 켜기 |
| 받는 폰이 아이폰이라 파란색으로 옴 | 정상 동작이지만 SMS 가 아니라 iMessage 로 간 것입니다. 안드로이드 폰이나 두 번째 번호로도 한 번 확인해 주세요 |
| 짧은 시간에 여러 번 보냈더니 막힘 | 통신사 스팸 제한일 수 있습니다. 잠시 쉬었다가 다시 |

## 참고
- 이 방식은 애플이 공식 지원하는 방법이 아니라 **맥OS 버전에 따라 안 될 수 있습니다.** 그래서 행사 전에 이 테스트로 먼저 확인합니다.
- 문자는 **아이폰의 번호**로 나갑니다. 맥북과 아이폰이 서로 다른 사람 것이면 Apple ID 공유가 필요해서 권하지 않습니다.
- 파일 생성 방법(개발자용): `node tools/mac-sms-test/make.js`
