# gyeoL 안내 문자 발송 설명서 (팀원용)

참가자·신청자에게 안내 문자를 보내는 방법입니다. 웹앱에서 **발송 스크립트 파일**을 받아 **맥북**에서 실행하면, 연결된 **아이폰**의 번호로 문자가 한 명씩 나갑니다. 별도 문자 서비스 가입은 필요 없습니다.

> 이 방식은 맥북 메시지 앱을 이용하는 비공식 방법이라 맥OS 버전에 따라 안 될 수 있습니다. 처음에는 소수 인원(본인·팀원 번호)으로 테스트하세요.

## 0. 준비물 (처음 한 번)
- 맥북 1대 + 아이폰 1대 (**같은 Apple ID**). 문자는 **그 아이폰의 번호**로 나갑니다. 참가자에게는 그 번호가 보내는 사람으로 보입니다.
- 아이폰: **설정 → 메시지 → 문자 메시지 전달**에서 내 맥북 이름을 켜고, 맥북에 뜨는 인증 번호를 아이폰에 입력합니다. (아이폰 언어가 영어면 Settings → Messages → Text Message Forwarding)
- 맥북: 메시지 앱에 로그인되어 있어야 합니다. 메시지 앱에서 아무 번호로 직접 문자를 보내 **초록색(SMS) 말풍선으로 나가는지** 먼저 확인하세요.
- 진행자 화면 접속: `https://gyeol.rotationdating.workers.dev/admin.html` 에서 **진행자 마스터키**를 입력합니다. (마스터키는 운영진에게 따로 받으세요. 이 문서·채팅방에 적지 마세요.)

## 1. 문자는 5종류, 이 순서로 보냅니다
진행자 화면의 **안내 문자** 탭에서 위쪽 버튼으로 종류를 고릅니다.

| 종류 | 때 | 받는 사람 |
|---|---|---|
| 신청 완료 | 신청·입금 확인 후 (하루 한 번 모아서 가능) | 신규 신청자 |
| 참가 확정 | 행사 2일 전 (신청자를 참가자로 배정한 뒤) | 그 회차 참가자 |
| 장소 안내 | 행사 1일 전 | 그 회차 참가자 |
| 결과 안내 | 최종 선택 결과를 공개한 직후 | 그 회차 참가자 |
| 행사 취소 | 행사를 열 수 없을 때 | 그 회차 참가자 + 그 회차를 신청한 배정 전 신청자 |

- 참가 확정·장소 안내·결과 안내·행사 취소는 **회차**를 먼저 고릅니다.
- **장소 안내**는 일시·**장소·지도 링크**를 입력해야 발송 버튼이 활성화됩니다.
- **결과 안내**는 최종 선택 탭에서 결과를 공개한 뒤에만 목록이 나옵니다. 결과 내용·연락처는 문자에 들어가지 않고, 링크만 보냅니다.

## 2. 보내는 순서
1. 종류와 회차를 고릅니다.
2. 목록을 확인합니다. 기본으로 **미발송 사람만** 보이고 전원이 선택돼 있습니다. 늦게 등록된 사람은 나중에 같은 화면에서 미발송만 골라 보내면 됩니다. 일부만 보내려면 체크를 풀거나 [검색]을 쓰세요. **필터로 가려진 사람은 보내지 않습니다.**
3. 필요하면 [문안 보기·수정]에서 문구를 확인합니다. (수정한 문구는 서버에 저장돼 다른 기기에서도 같습니다.)
4. **[발송 스크립트 받기]**를 누르면 `.applescript` 파일이 내려받아집니다.
5. 그 파일을 **맥북**으로 가져옵니다. (윈도우 등에서 받았다면 **AirDrop**을 권장합니다. 파일에 전화번호가 들어 있어 메일·메신저는 피하세요.)
6. 파일을 더블클릭해 **스크립트 편집기**로 열고, 위쪽 **▶(실행)**을 누릅니다.
7. 처음 한 번 "스크립트 편집기가 메시지를 제어하려고 합니다" 창이 뜨면 **허용**합니다.
8. 한 명씩 **5초 간격**으로 나갑니다(30명이면 2~3분). 끝날 때까지 맥북을 닫거나 재우지 마세요. 아이폰도 켜져 있어야 합니다.
9. 끝나면 "발송 요청 N건 완료, 실패 N건"이 뜹니다. 실패한 번호가 있으면 함께 표시됩니다.
10. 앱으로 돌아와 **[발송 완료로 표시]**를 **두 번** 누릅니다. 그래야 다음에 같은 사람에게 다시 나가지 않습니다.
11. 받은 파일을 **삭제**하고 휴지통도 비웁니다. (전화번호가 들어 있음)

### 주의
- 실패한 번호가 있으면 [발송 완료로 표시]를 누르기 **전에**, 목록에서 그 사람들의 체크를 풀고 표시하세요. 표시는 선택된 사람 전원을 기록합니다.
- 실행이 중간에 멈췄다면 앱은 어디까지 나갔는지 모릅니다. 아이폰 메시지 기록으로 확인해 나간 사람만 체크해 표시하세요.
- 같은 사람에게 **같은 종류를 다시 보내려면** 발송 상태를 "전체"로 바꾸고 체크하면 됩니다. 중복 발송이 되니 신중히.
- 문안·장소·지도 링크는 오타가 없는지 **보내기 전에** 꼭 다시 보세요. 나간 문자는 되돌릴 수 없습니다.

## 3. 테스트 먼저
- 안내 문자 탭 맨 아래 **[테스트로 1건 먼저 보내기]**에 **다른 사람 번호**(팀원·본인의 다른 폰)를 넣고 [테스트 스크립트 받기] → 맥북에서 실행합니다. 보내는 아이폰 자기 번호로는 확인이 어렵습니다.
- 확인할 것: 문자가 도착했는지 · 이모지가 깨지지 않는지 · 일반 문자(초록/SMS)로 왔는지, 받는 사람이 아이폰이면 파란 iMessage로 왔는지.

## 4. 문제가 생기면
| 증상 | 확인 |
|---|---|
| 권한 창이 안 뜨거나 오류 | 맥북 **시스템 설정 → 개인정보 보호 및 보안 → 자동화**에서 스크립트 편집기의 **메시지**를 켜기 |
| "완료"인데 문자가 안 감 | 메시지 앱에서 직접 SMS가 나가는지, 아이폰이 켜져 있고 연결됐는지, 문자 메시지 전달이 켜져 있는지 |
| 짧은 시간에 여러 번 보냈더니 막힘 | 통신사 스팸 제한일 수 있음. 잠시 쉬었다가 다시 |
| 발송 버튼이 비활성 | 장소 안내는 장소·지도 필수, 결과 안내는 결과 공개 필요, 선택된 사람이 0명이면 비활성 |
| 앱에 이상한 화면·오류 | 화면 캡처와 오류 문구를 개발 담당에게 전달 |

## 5. 개인정보 안전 수칙
- 스크립트 파일·마스터키·참가자 명단은 외부에 공유하지 않습니다.
- 발송이 끝나면 파일을 삭제합니다.
- 행사 후 마스터키는 새로 바꿉니다(개발 담당이 처리).
