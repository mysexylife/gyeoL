# gyeoL 안내 문자 양식 (다듬기용)

앱의 기본 문구와 같은 내용입니다. 팀원이 다듬은 문구는 진행자 화면 → 문자 패널의 **문안** 칸에 붙여 넣으면 서버에 저장되어 모든 기기에 반영됩니다.
(행사 취소 안내도 앱 [문자] 탭에 있습니다.)

## 쓸 수 있는 자리표시 (값이 비어 있으면 그 줄은 자동으로 빠짐)
| 자리표시 | 들어가는 값 | 쓸 수 있는 문자 |
|---|---|---|
| `{이름}` | 받는 사람 이름 | 전체 |
| `{희망날짜}` | 신청한 날짜·시간(여러 개면 쉼표로) | 신청 완료 |
| `{일시}` | 진행자가 입력한 일시 (비우면 회차 날짜) | 참가 확정 · 장소 안내 · 행사 취소 |
| `{장소}` | 진행자가 입력한 장소 | 장소 안내 |
| `{지도}` | 진행자가 입력한 지도 링크 | 장소 안내 |
| `{도착시간}` | 일시의 시작 시각 10분 전 (시각이 없으면 줄이 빠짐) | 장소 안내 |
| `{링크}` | 참가자 입장 주소 | 결과 안내 |
| `{취소사유}` `{환불안내}` | 문자 탭에서 직접 입력한 값 | 행사 취소 |

## 1. 신청 완료 — 신규 신청자(아직 신청 안내를 못 받은 사람)에게
언제: 신청과 입금이 확인된 뒤(하루 한 번 모아서 보내도 됨). 기본 필터: 미발송. 입금 정보·결제 안내는 넣지 않음.
```
안녕하세요, 로테이션 소개팅 [결] 운영진입니다 :)
신청과 입금이 확인되어 예약이 잘 접수되었어요!

신청하신 날짜: {희망날짜}

일시와 장소는 행사 전날 문자로 다시 확정해서 안내드릴게요.
```

## 2. 참가 확정 (2일 전) — 신청자를 참가자로 배정한 뒤, 그 회차 참가자에게
언제: 행사 2일 전. 늦게 등록한 참가자는 나중에 같은 화면에서 [미발송]만 골라 보냅니다. 팀이 다듬어 주세요(새로 추가한 초안).
```
안녕하세요, 로테이션 소개팅 [결]입니다 🧶
{일시} 로테이션 소개팅 참가가 확정되었어요!

장소와 자세한 안내는 행사 전날 문자로 다시 알려드릴게요.
혹시 참석이 어려워지시면 미리 연락 부탁드려요.
그날 뵐게요 💘
```

## 3. 장소 안내 (1일 전) — 그 회차 참가자에게
언제: 행사 전날. 일시·장소·지도 링크는 필수 입력.
```
안녕하세요, 로테이션 소개팅 [결]입니다 🧶
행사 장소와 시간 안내드립니다!

📅 일시 : {일시}
📍 장소 : {장소}
🗺️ 지도 : {지도}

⏰ 원활한 진행을 위해 {도착시간}까지 꼭 도착해주세요!
늦게 오시면 로테이션 순서에 함께하기 어려울 수 있어요.

🎓 입장할 때 학생증을 확인해요. 실물이나 모바일 학생증 등 학교를 확인할 수 있는 물품을 꼭 챙겨주세요!
☕ 간단한 다과가 준비되어 있어요.

혹시 늦거나 못 오시게 되면 전날까지 미리 연락 부탁드려요.
내일 뵐게요 💘
```

## 4. 결과 안내 — 그 회차 참가자에게, 결과 공개 직후
언제: 진행자가 최종 선택 결과를 공개한 뒤. 결과 내용·연락처는 문자에 넣지 않고 링크만.
```
안녕하세요, 로테이션 소개팅 [결] 운영진입니다 :)
오늘 참여해 주셔서 감사합니다!

최종 선택 결과가 나왔어요.
아래 링크에서 로그인 후 최종선택 탭에서 확인해 주세요.
{링크}

인스타그램을 팔로우하면 다음 회차 소식과 콘텐츠를 확인하실 수 있어요ㅎㅎ
→ @gyeol.meet_official
```

## 5. 행사 취소 안내 — 그 회차 참가자 + 그 회차를 신청했지만 아직 배정 전인 신청자에게
언제: 인원 미달·장소 문제·기상 악화 등으로 행사를 열 수 없을 때.
`{취소사유}`와 `{환불안내}`는 [문자] 탭에서 칸에 직접 적습니다(비어 있으면 보낼 수 없음). `{일시}`는 비우면 회차 날짜로 채워집니다.
```
안녕하세요, 로테이션 소개팅 [결] 운영진입니다.
{일시} 행사가 {취소사유} 때문에 부득이하게 취소되었어요. 기대하고 계셨을 텐데 정말 죄송합니다 🙏

{환불안내}

번거로움을 드려 죄송합니다. 다음 회차에서 꼭 다시 뵙고 싶어요.
소식은 인스타그램 @gyeol.meet_official 에서 확인하실 수 있어요.
```
팀이 정할 것: 취소 사유 표현(구체적으로 / 일반적으로), 환불 방법과 기한, 이월 허용 여부와 안내 방식, 문의 연락처, 발송 시점(결정 즉시 / 전날까지).
예) `{환불안내}` 칸: "입금해 주신 참가비는 영업일 3일 이내 입금 계좌로 전액 환불해 드릴게요. 다른 날짜로 옮기고 싶으시면 이 번호로 문자 주세요."

## 다듬을 때 체크리스트
- 첫 줄에 [결] 운영진이라고 밝혔는지 (스팸으로 오해되지 않게)
- 링크·지도 주소가 정확한지, 개인정보(결과·연락처)를 문자에 넣지 않았는지
- 이모지는 유지해도 되지만, 받는 폰에서 깨지지 않는지 테스트 문자로 확인
- 한 통이 너무 길면(스크롤이 길면) 핵심을 위쪽에 두기
