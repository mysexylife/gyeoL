# gyeoL 안내 문자 양식 (팀 수정본 · 앱 반영 완료)

앱의 기본 문구를 다듬은 버전입니다. 진행자 화면 → **안내 문자** 탭의 **문안 보기·수정**에 붙여 넣으면 서버에 저장됩니다(앱의 기본 문구도 이 내용으로 바꿔 두었습니다).

## 바뀐 점 요약
- 발송 흐름을 **신청 완료 → 2일 전 참가 확정 → 1일 전 장소 안내 → 결과 안내 (+ 취소 안내)** 로 정리
- 2일 전 참가 확정(2번)과 취소 안내(5번)는 앱에 추가했습니다(5종).

## 쓸 수 있는 자리표시 (기존과 동일)
| 자리표시 | 들어가는 값 | 쓸 수 있는 문자 |
|---|---|---|
| `{이름}` | 받는 사람 이름 | 전체 |
| `{희망날짜}` | 신청한 날짜·시간(여러 개면 쉼표로) | 1. 신청 완료 |
| `{일시}` | 진행자가 입력한 일시 (비우면 회차 날짜) | 2. 참가 확정(신규), 3. 장소 안내, 5. 취소 |
| `{장소}` | 진행자가 입력한 장소 | 3. 장소 안내 |
| `{지도}` | 진행자가 입력한 지도 링크 | 3. 장소 안내 |
| `{도착시간}` | 일시의 시작 시각 **10분 후** (예: 18:00 행사 → 18:10) (앱 반영 완료) | 3. 장소 안내 |
| `{링크}` | 참가자 입장 주소 | 4. 결과 안내 |

> 2번·5번의 `{일시}` 는 앱에 반영되어 있습니다. `{도착시간}`은 일시의 시작 시각 **10분 후**로 계산됩니다.

---

## 1. 신청 완료 — 신청자에게 (기존 '예약 확인' 대체)
언제: 신청과 입금이 확인된 뒤.
```
안녕하세요, 로테이션 소개팅 [결] 운영진입니다 :)
{이름}님, 신청과 입금이 확인되어 신청이 완료되었어요 💌

신청하신 날짜: {희망날짜}

성비를 고려해 참가 확정 여부는 행사 2일 전까지 문자로 안내드릴게요.
조금만 기다려주세요 🙂
```

## 2. 참가 확정 — 확정된 참가자에게, 행사 2일 전 (신규)
언제: 진행자가 회차 배정을 마친 뒤, 행사 2일 전.
```
안녕하세요, 로테이션 소개팅 [결] 운영진입니다 :)
{이름}님, 로테이션 소개팅 참가가 확정되었어요 🎉

📅 일시 : {일시}
📍 장소 : 신촌·홍대 근처 카페

정확한 장소와 지도 링크는 행사 하루 전에 문자로 다시 안내드릴게요.

설레는 만남 준비해두고 기다릴게요 💗
```

## 3. 장소 안내 — 그 회차 참가자에게, 행사 전날 (기존 '전날 확정')
언제: 행사 전날. 일시·장소·지도 링크는 필수 입력.
```
안녕하세요, 로테이션 소개팅 [결] 운영진입니다 🧶
내일 행사 장소와 시간 안내드립니다!

📅 일시 : {일시}
📍 장소 : {장소}
🗺️ 지도 : {지도}

⏰ 원활한 진행을 위해 {도착시간}까지 꼭 도착해주세요!

🎓 입장할 때 학생증을 확인해요. 실물이나 모바일 학생증 등 학교를 확인할 수 있는 물품을 꼭 챙겨주세요!
☕ 간단한 음료와 다과가 준비되어 있어요.

혹시 늦거나 못 오시게 되면 미리 연락 부탁드려요.
내일 뵐게요 💘
```

## 4. 결과 안내 — 그 회차 참가자에게, 결과 공개 직후
언제: 진행자가 최종 선택 결과를 공개한 뒤. 결과·연락처는 문자에 넣지 않고 링크만.
```
안녕하세요, 로테이션 소개팅 [결] 운영진입니다 :)
오늘 함께해 주셔서 정말 감사합니다 🙏

최종 선택 결과가 공개되었어요!
아래 링크에서 로그인 후 '최종선택' 탭에서 확인해 주세요 💘
{링크}

서로 선택한 분이 있다면 그곳에서 연락처를 확인하실 수 있어요.
인스타그램을 팔로우하면 다음 회차 소식과 콘텐츠를 가장 먼저 받아보실 수 있어요 ㅎㅎ
→ @gyeol.meet_official
```

## 5. 취소 안내 — 참가가 어려워진 신청자에게 (신규)
언제: 성비·인원 문제로 해당 회차 참여가 어려워졌을 때, 결정 즉시.
```
안녕하세요, 로테이션 소개팅 [결] 운영진입니다.
{이름}님, [결]에 신청해 주셔서 진심으로 감사드려요 🙏

아쉽게도 {일시} 회차는 성비 문제로 부득이하게 참여가 어려워졌어요.
기대하고 계셨을 텐데 정말 죄송합니다.

혹시 다음 회차로 옮겨서 참여하실 수 있을까요?
다음 회차 일정에 맞춰 우선으로 자리를 마련해 드릴게요 💌

▶ 다음 회차로 이동을 원하시면 "이동"
▶ 환불을 원하시면 "환불"과 함께 환불받으실 계좌

이 번호로 답장 주시면 바로 처리해 드릴게요.
환불을 선택하셔도 참가비는 전액 돌려드려요.

소식은 인스타그램 @gyeol.meet_official 에서도 확인하실 수 있어요.
```

## 앱에서의 동작
- 5종: 신청 완료(신청자) · 참가 확정(그 회차 참가자) · 장소 안내(그 회차 참가자) · 결과 안내(그 회차 참가자) · 행사 취소(그 회차 참가자 + 그 회차를 신청했지만 배정 전인 신청자)
- 기본 필터는 모두 "미발송"이라, 늦게 등록한 사람은 나중에 같은 화면에서 미발송만 골라 보냅니다.
- 이미 앱에 저장해 둔 문안이 있으면 기본 문구보다 우선합니다. 새 양식을 쓰려면 문안 칸에서 [기본 문구로 되돌리기]를 누르세요.

## 팀이 확인할 것
- 5번: 다음 회차 일정과 가격이 다르면(예: 얼리버드) 차액 안내 문구 추가 여부 결정
- 행사 전체 취소(장소·기상 문제 등)용 문구는 5번을 바탕으로 사유만 바꿔 문안 칸에서 수정해 사용
